# ☀️ 开张啦

这里是 **芒果干的太阳浴场**，第一篇文章。

## 为什么要开这个博客

想找个安静的地方放点东西 —— 技术笔记、日常碎片，还有一些没地方说的碎碎念。

比起发在社交平台上，自己的站更自由：想写多长写多长，想怎么排版怎么排版，也不用担心哪天平台改规则。

## 这里会写什么

- 🛠️ **技术笔记** —— 折腾电脑、写代码时踩过的坑
- 🎮 **兴趣相关** —— VR、游戏、折腾硬件
- 🌱 **生活碎片** —— 想到什么写什么

## 怎么逛这个站

| 想做的事 | 去哪 |
|---|---|
| 看全部历史文章 | 导航栏 **归档** |
| 按主题找 | 左侧 **分类** / **标签** |
| 搜关键词 | 右上角 **搜索** |
| 换明暗主题 | 右上角月亮图标 |

## 关于技术栈

这个站用 [Astro](https://astro.build) + [Fuwari](https://github.com/saicaca/fuwari) 搭建，纯静态，托管在 GitHub Pages 上。

写文章就是写 Markdown 文件，扔进 `src/content/posts/` 就行。
